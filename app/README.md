# app

Next.js frontend. Uses [viem](https://viem.sh) with its built-in `monadTestnet` chain (see `src/lib/monad.ts`).

```bash
cp .env.example .env.local   # optional: custom RPC
npm install
npm run dev                  # http://localhost:3000
```

See the [root README](../README.md) for the full project.
